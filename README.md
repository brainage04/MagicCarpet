# MagicCarpet

MagicCarpet is a Minecraft 26.2 mod for Fabric and NeoForge that adds three craftable, rideable flying carpets. Install it on both the client and server.

## Requirements

- Minecraft 26.2
- Java 25 or newer
- Fabric Loader 0.19.3 or newer and Fabric API, or NeoForge 26.2.0.41-beta or newer

## Migrating from the Fabric-only release

Install exactly one MagicCarpet JAR matching the server's loader: Fabric requires Fabric Loader and Fabric API; NeoForge requires NeoForge. Remove the old MagicCarpet JAR before switching loaders, and use the matching JAR on both client and server. The mod ID remains `magic_carpet`, so existing world content and data paths remain unchanged. For development and releases, root `./gradlew build` produces separate Fabric and NeoForge artifacts under `build/libs`.

## Carpet tiers

| Tier | Recipe | Horizontal speed | Climb/descent speed | Acceleration time | Coast-to-stop time |
| --- | --- | ---: | ---: | ---: | ---: |
| Basic | 6 wool of any colour and 3 phantom membranes | 12 blocks/s | 6 blocks/s | 2 seconds | 4 seconds |
| Advanced | 1 basic carpet, 2 blaze rods, 2 breeze rods, and 4 gold blocks | 24 blocks/s | 12 blocks/s | 1 second | 2 seconds |
| Legendary | 1 advanced carpet, 1 nether star, 2 dragon's breath, 2 diamond blocks, and 3 shulker shells | 48 blocks/s | 24 blocks/s | 0.5 seconds | 1 second |

Horizontal and vertical speeds are independent, so climbing or descending while moving at full horizontal speed is about 12% faster overall. Releasing the controls, or dismounting, lets the carpet coast to a stop over roughly 11 blocks at full speed.

Collecting wool unlocks the basic carpet recipe. Each crafted carpet unlocks the next tier's advancement path.

Each tier looks different: basic carpets have a plain rolled edge, advanced carpets add a gold cord and tassels, and legendary carpets add curled front corners and threads that glow in the dark. Carpets ripple, bob, and sway while hovering, stream their tassels behind them in flight, and shed tier-specific particles.

## Controls

- Right-click a block with a carpet item to place the carpet.
- Right-click the placed carpet to ride it.
- Use the normal movement keys for horizontal motion.
- Hold jump while looking forward or upward to ascend.
- Hold jump while looking steeply downward to descend.
- Sneak to dismount.

Carpet riders do not take fall damage while mounted. Each carpet can carry two passengers.

## Development

```shell
./gradlew build
./gradlew runClientGameTest
```

The client GameTest validates dedicated-server entity registration, recipe loading, spawning, and rendering for all three carpet tiers.

The carpet textures, item textures, and item models are generated by `tools/generate_carpet_assets.py` (standard library only); edit the script rather than the PNGs, and keep its UV layout in step with `MagicCarpetEntityModel`. The mod icon is a Blender render of the same models and textures; see [docs/icon/README.md](docs/icon/README.md) to regenerate it after changing either.

Release automation is documented in [docs/RELEASE.md](docs/RELEASE.md). Optional Modrinth publishing is documented in [docs/MODRINTH.md](docs/MODRINTH.md).
