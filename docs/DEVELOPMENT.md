# Development

Check `heavy status` before starting a build or GameTest run. Run Gradle through `heavy`, with `--no-daemon` and the options-file override so client tasks do not copy personal game options.

```shell
heavy --quick -- ./gradlew --no-daemon build
heavy --mem 6G -- ./gradlew --no-daemon runAllGameTests
```

`runAllGameTests` runs Fabric and NeoForge development and production server GameTests, plus the Fabric production client GameTests. The client scenarios connect to a dedicated server.

`:fabric:runVanillaServerClientGameTest` (from MinecraftModConventions) runs the same client GameTests against a plain vanilla server without MagicCarpet. `MagicCarpetVanillaServerClientGameTest` then checks that no carpet is offered in creative there and that taking one does not get the player kicked, and that sending the held-back packet does, so the check would catch the kick. It is not part of `runAllGameTests`.

```shell
heavy --mem 6G -- ./gradlew --no-daemon :fabric:runVanillaServerClientGameTest
```

The carpet textures, item textures, and item models are generated by `tools/generate_carpet_assets.py` (standard library only); edit the script rather than the PNGs, and keep its UV layout in step with `MagicCarpetEntityModel`. The mod icon is a Blender render of the same models and textures; see [icon/README.md](icon/README.md) to regenerate it after changing either.
